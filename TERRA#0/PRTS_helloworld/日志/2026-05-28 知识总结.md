# 2026-05-28 知识总结

## TOML 是什么

`.toml` 是配置文件格式，用 `key = value` 和 `[section]` 保存程序配置。

例子：

```toml
[features]
remote_connections = true
remote_control = true
```

程序读取 TOML 的方式：

```text
读取文件 -> TOML 解析器解析 -> 得到字典/对象 -> 程序使用配置值
```

## Codex 的 config.toml

位置：

```text
C:\Users\admin\.codex\config.toml
```

作用：保存 Codex 的模型、功能开关、插件、MCP、项目可信度、Windows 沙箱等配置。

本次远程连接关键项：

```toml
[features]
remote_connections = true
remote_control = true
```

含义：

- `remote_connections`：启用远程连接能力。
- `remote_control`：允许这台电脑注册为手机 ChatGPT 可连接的 Codex 设备。

## Codex 手机端权限

手机连接 Windows Codex 时，核心不是局域网直连，而是：

```text
手机 ChatGPT -> OpenAI/Codex 云端 -> Windows Codex remote-control
```

手机端的权限模式大致分两类：

### 默认自动完全访问

含义：手机端连接后，默认允许 Codex 以较高自动化权限在电脑上执行任务。

特点：

- 更省确认步骤。
- 适合你信任当前项目和当前会话时使用。
- 风险更高，因为文件读写、命令执行、项目操作会更自动。

### 自定义

含义：手动限制手机端远程 Codex 可以访问或执行的范围。

常见可控项包括：

- 允许访问哪些项目目录。
- 是否允许自动执行命令。
- 是否需要每次确认高风险操作。
- 是否限制文件读写范围。
- 是否限制网络、插件、MCP 或终端能力。

作用：降低远程控制风险，把权限收紧到当前任务真正需要的范围。

## 简单判断

```text
自己电脑 + 信任项目 + 需要高效率：可以用默认自动完全访问
不确定项目安全性 + 远程操作 + 涉及敏感文件：用自定义
```

## 今日实际经验

连接手机时遇到两个主要问题：

```text
Multi-factor authentication required -> 重新 codex logout / codex login，完成 MFA
os error 10060 -> Windows 直连 OpenAI 超时，改走 Clash 127.0.0.1:7890
```

最终启动方式：

```powershell
$env:HTTP_PROXY = 'http://127.0.0.1:7890'
$env:HTTPS_PROXY = 'http://127.0.0.1:7890'
$env:ALL_PROXY = 'http://127.0.0.1:7890'
$env:NO_PROXY = 'localhost,127.0.0.1,::1'
codex app-server --listen off --remote-control
```

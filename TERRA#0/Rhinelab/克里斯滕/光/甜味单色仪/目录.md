# 甜味单色仪

## 思维导图
- **课题目标**：构造甜味单色仪，并优化输出光谱的最窄波长带宽。
- **旋光基础**：线偏振光可分解为左右圆偏振光，糖溶液中的折射率差产生旋光角。
- **色散模型**：用 Drude 型公式描述比旋光度和旋光角随波长变化，并记录蔗糖文献参数。
- **光强筛选**：检偏器角度与旋光角差值通过马吕斯定律决定相对透过强度。
- **光谱公式**：将 Drude 色散代入马吕斯定律，得到 $I_{\mathrm{rel}}(\lambda,\beta)$。
- **带宽优化**：用 FWHM 与 HWHM 衡量输出光谱宽度，扫描检偏角寻找最小值。

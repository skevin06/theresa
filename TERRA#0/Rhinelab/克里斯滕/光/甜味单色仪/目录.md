# 甜味单色仪

## 思维导图
- **课题目标**：构造甜味单色仪，并优化输出光谱的最窄波长带宽。
- **旋光基础**：糖溶液使不同波长产生不同旋光角，来源于左右圆偏振折射率差。
- **色散模型**：用 Drude 型公式描述旋光角随波长变化，并可在远离吸收峰时展开。
- **光强筛选**：检偏器角度与旋光角差值通过马吕斯定律决定相对透过强度。
- **带宽优化**：用 FWHM 衡量输出光谱宽度，扫描检偏角寻找最小值。

# 随机误差

## P0 来源轴

| 来源轴 | 来源位置 | 内容 |
|---|---|---|
| ZH-01 | 知乎话题“系统误差”摘录 | 随机误差也称偶然误差，误差的绝对值和符号不可预知 |
| ZH-05 | 知乎话题“概率论”摘录 | 大量测量结果不完全一致时，需要研究误差规律和置信理论 |

## P0 核心定义

随机误差是不可预知的测量波动：同一量重复测量时，每次误差的大小和方向不固定，只能通过统计规律描述。

## P0 和概率论的关系

| 主题 | 说明 |
|---|---|
| 大量重复测量 | 单次结果不可靠时，用多次结果观察整体规律 |
| 大数定律 | 样本足够多时，平均结果更稳定 |
| 中心极限定律 | 多种小扰动叠加时，结果常按近似正态规律波动 |
| 置信理论 | 用概率语言说明结果落在某个范围内的可信程度 |

## P1 处理步骤

1. 不把单次测量结果当作真实值。
2. 保留多次测量数据。
3. 计算平均值、离散程度和置信范围。
4. 判断随机波动是否超过测量任务允许范围。
5. 如果波动过大，先增加重复测量，再检查环境和操作稳定性。

## P2 易错点

| 易错点 | 修正 |
|---|---|
| 把随机误差当成可直接修正的固定偏差 | 随机误差主要靠重复测量和统计描述 |
| 只报平均值不报离散程度 | 平均值不能说明测量结果有多稳定 |
| 把随机误差和系统误差混成一类 | 系统误差看偏倚，随机误差看波动 |

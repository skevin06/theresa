# MSA 测量系统案例

## P2 来源轴

| 来源轴 | 来源位置 | 例子 |
|---|---|---|
| ZH-03 | 知乎盐选“第三章 MSA：测量系统分析” | 新项目试产前、年度定期、量具分辨率、测量系统稳定性 |

## 作者为什么举它

MSA 用来说明：产品数据是否可信，先要确认测量系统本身是否可靠。否则过程调整可能是在修正测量误差，而不是修正产品问题。

## 对应操作步骤

1. 新项目导入或定期复核时启动 MSA。
2. 明确测量对象和允许误差范围。
3. 检查量具分辨率是否能识别关键变化。
4. 评估测量系统误差大小。
5. 评估稳定性和偏倚。
6. 判断改善方向：人员培训、方法调整、仪器校准或更换。

## 工程意义

MSA 把误差问题从“某个工具准不准”扩展到“整个测量过程能不能支持决策”。这适合生产、检测、质量管理场景。

## 容易错在哪里

| 错误 | 后果 |
|---|---|
| 只检查量具 | 忽略人员、流程、软件和环境 |
| 不看分辨率 | 测量系统可能分不出真实变化 |
| 不做稳定性复查 | 长期漂移会被误认为产品变化 |

# 测量不确定度评定

## P0 来源轴

| 来源轴 | 来源位置 | 内容 |
|---|---|---|
| ZH-04 | 知乎专栏“CNAS 软件检测实验室测量不确定度评定程序” | 检测实验室应分析不确定度对检测结果的贡献 |
| ZH-04 | 同文“来源识别” | 用人、机、料、法、环、测、抽排查不确定度来源 |

## P0 核心定义

测量不确定度关注的是结果可能变化的范围。它不是简单说“错了多少”，而是说明检测结果受哪些因素影响、可信范围有多大。

## P1 来源识别步骤

1. 明确检测结果是否为数值结果。
2. 如果结果可数值化，列出影响结果的主要分量。
3. 按“人、机、料、法、环、测、抽”逐项排查。
4. 判断每个分量是否对结果有显著贡献。
5. 对关键分量进行评定，形成不确定度说明。

## P1 来源树

```text
测量不确定度来源
├─ 人：操作重复性、读数偏差
├─ 机：校准误差、重复性、设备漂移
├─ 料：样品均匀性、稳定性
├─ 法：方法检出限、拟合偏差、前处理波动
├─ 环：温度、湿度、噪声等环境变化
├─ 测：测量过程和记录方式
└─ 抽：抽样方法带来的偏差
```

## P2 易错点

| 易错点 | 修正 |
|---|---|
| 把不确定度等同于错误 | 不确定度是结果分散范围的表达 |
| 只看仪器，不看方法和人员 | 评定必须覆盖整个检测过程 |
| 不列来源就直接给结论 | 先识别分量，再评定贡献 |

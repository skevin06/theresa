# MSA 测量系统分析

| 来源轴 | 来源位置 | 内容 |

## P0 核心定义

测量系统不是单个仪器，而是获得测量结果的整个过程：操作、程序、设备、量具、软件和人员都在系统内。

| 概念 | 含义 |
|---|---|
| 测量系统 | 获得测量结果的完整过程 |
| 量具 | 用来取得测量结果的装置 |
| 分辨率 | 测量系统识别被测特性微小变化的能力 |
| 偏倚 | 测量结果相对参考值的稳定偏离 |

## P1 MSA 操作思路

1. 明确被测特性和客户允许误差。
2. 列出测量系统：人、机、软件、量具、程序。
3. 检查量具分辨率是否够用。
4. 评估测量误差是否在可控范围内。
5. 评估稳定性：随时间推移，测量变异是否受控。
6. 评估偏倚：测量结果是否长期偏大或偏小。
7. 根据问题决定改进方向：培训人员、调整方法或校准仪器。

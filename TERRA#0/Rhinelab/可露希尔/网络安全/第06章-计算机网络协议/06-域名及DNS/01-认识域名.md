# 认识域名

## P0 IP 地址与域名

**时间轴：23:30-28:00**

IP 地址是互联网上计算机唯一的逻辑地址，通过 IP 地址实现不同计算机之间的通信。作者强调：每台联网计算机都需要通过 IP 地址来相互联系和分别。

由于 IP 地址由容易混淆的数字串构成，人们很难记住所有计算机的 IP 地址，所以在 IP 地址基础上发展出更容易识别的符号化标识，这就是域名。

## P1 域名的作用

| 内容 | 视频中的含义 |
|---|---|
| 网站名字 | 相当于互联网上某台计算机或计算机组的名称 |
| 电子方位 | 用于数据传输时标识计算机的位置 |
| 易记标识 | 用字母和数字组合，逐渐替代 IP 地址成为访问入口 |

## P2 视频例子

视频中举到：常见的 `www.baidu.com` 就是域名。

## 易错点

- 域名不是 IP 地址本身，而是更容易记忆的符号化标识。
- 域名能被人读懂，但计算机最终仍需要 IP 地址完成定位。

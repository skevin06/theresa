# DNS 服务器

## P0 定义

**时间轴：28:00-28:50**

DNS 服务器用于把域名和与之对应的 IP 地址进行转换。

## P1 为什么需要 DNS

域名更容易被用户接受和使用，但计算机只能识别数字构成的 IP 地址，不能直接读取域名。要达到访问效果，就需要把域名翻译成 IP 地址；DNS 域名解析承担的就是这种翻译效果。

```text
用户输入域名
→ DNS 将域名转换成对应 IP
→ 计算机按 IP 地址访问目标主机或服务
```

## 易错点

- DNS 不是网站本身，而是域名到 IP 地址的转换服务。
- 本 P 只讲到 DNS 的基本作用，没有展开完整递归/迭代解析流程。

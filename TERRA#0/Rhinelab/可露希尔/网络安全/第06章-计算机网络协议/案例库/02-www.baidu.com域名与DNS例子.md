# `www.baidu.com` 域名与 DNS 例子

## P2 作者为什么举这个例子

视频用 `www.baidu.com` 说明：用户更容易记住域名，而不是记住一串 IP 地址。

## 对应哪个网络操作

```text
输入 www.baidu.com
→ DNS 服务器把域名转换为对应 IP 地址
→ 计算机按 IP 地址访问对应网站服务
```

## 网络意义

这里没有物理几何意义，对应的是网络定位意义：域名是人容易识别的入口，IP 地址是计算机实际识别的逻辑地址。

## 容易错在哪里

- 以为域名可以直接被计算机识别；视频强调计算机识别的是 IP。
- 把 DNS 当成“存网页的服务器”；这里 DNS 承担的是域名和 IP 的转换。

# 网络协议概念

## P0 定义

**时间轴：03:30-04:30**

网络协议是计算机连接和通信时共同遵守的规则。作者用道路交通规则作类比：车在路上行驶要按交通规则走，计算机在网络里通信也要遵守约定。

## P1 读协议时先看什么

| 问题 | 对应本章内容 |
|---|---|
| 谁和谁通信？ | 客户端、服务端 |
| 用什么协议？ | HTTP、HTTPS、TCP |
| 走哪个端口？ | HTTP 80，HTTPS 443 |
| 是否加密？ | HTTP 明文，HTTPS 通过 SSL/TLS 加密 |
| 连接如何建立和断开？ | TCP 三次握手、四次挥手 |

## P2 视频例子

作者把协议类比为“路上的交通规则”，目的不是讲交通，而是说明：通信双方只要不按同一套规则来，数据就无法被正确理解。

## 易错点

- 协议不是单个软件，也不是单个命令；它是一组通信约定。
- HTTP/HTTPS 是 Web 通信协议；TCP 是它们底层连接常见依赖的传输层协议。

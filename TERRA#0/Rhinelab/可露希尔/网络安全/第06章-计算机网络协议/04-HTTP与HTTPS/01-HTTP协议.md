# HTTP 协议

## P0 基本概念

**时间轴：04:30-09:30**

HTTP 是超文本传输协议，是用于分布式、协作式和超媒体信息系统的应用层协议。视频中把它说成浏览器和网站服务器之间传递 HTML 页面等信息的方法。

| 作者强调点 | 说明 |
|---|---|
| 无状态 | HTTP 本身不保存请求和响应之间的通信状态 |
| 默认端口 | 默认工作在 TCP 协议 80 端口 |
| URL 标识 | 用户访问 `http://` 开头的网站，一般就是标准 HTTP 服务 |
| 明文传输 | 不提供数据加密，敏感信息可能被截获读取 |

## P1 基本流程

**时间轴：09:30-11:00**

```text
地址解析
→ 封装 HTTP 请求数据包
→ 分装成 TCP 包，建立 TCP 连接（三次握手）
→ 客户机发送请求命令
→ 服务器响应
→ 服务器关闭 TCP 连接
```

## P1 判断和使用

- 看到 `http://`，先联想到：默认 80 端口、明文传输、Web 浏览器与服务器通信。
- 涉及账号、密码、信用卡等敏感信息时，不应只依赖 HTTP 明文传输。

## 易错点

- HTTP 的“无状态”不是说没有请求响应，而是协议本身不持久保存上下文状态。
- HTTP 可以跑在 TCP 上，但 HTTP 和 TCP 不是同一层协议。

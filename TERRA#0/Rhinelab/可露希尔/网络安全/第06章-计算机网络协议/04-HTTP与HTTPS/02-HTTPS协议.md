# HTTPS 协议

## P0 基本概念

**时间轴：11:00-12:30**

HTTPS 是超文本传输安全协议，是通过计算机网络进行安全通信的传输协议。作者强调：HTTPS 经由 HTTP 通信，但使用 SSL/TLS 加密数据包。

| 作者强调点 | 说明 |
|---|---|
| 认证 | 提供对网站服务器的身份认证 |
| 隐私 | 保护交换数据的隐私 |
| 完整性 | 防止数据在传输中被篡改 |
| 默认端口 | TCP 443 端口 |

## P1 工作流程

**时间轴：12:30-14:00**

```text
建立 TCP 连接（三次握手）
→ 客户端验证服务器数字证书
→ DH 算法协商对称加密算法密钥和 hash 算法密钥
→ SSL 安全加密隧道协商完成
→ 网页用加密方式传输
```

视频中还强调：网页传输时用协商出的对称加密算法和密钥加密，使用协商的 hash 算法保护数据完整性，保证数据不被篡改。

## P1 补充视频：TLS 握手

**时间轴：BV1KY411x7Jp 06:30-11:30**

技术蛋老师的 HTTPS 视频把这一段展开为：先走正常 TCP 三次握手，然后进入 TLS 握手，由 Client Hello、Server Hello、Certificate、Server Key Exchange、Client Key Exchange 等消息协商出会话密钥，最后用会话密钥传输 Application Data。

详见：[[04-TLS握手过程]]

## 易错点

- HTTPS 不是完全抛弃 HTTP，而是建立在 SSL/TLS 之上的 HTTP。
- 只看见 `https://` 不等于可以忽略证书；视频把“验证服务器数字证书”放在流程中。

# HTTP 与 HTTPS 的区别

## P0 对比表

**时间轴：14:00-18:30**

| 对比项 | HTTP | HTTPS |
|---|---|---|
| 传输方式 | 明文传输，数据未加密 | 传输过程加密 |
| 安全性 | 较差 | 较好 |
| 证书 | 不需要 CA 证书 | 需要向 CA 申请证书，通常要费用 |
| 默认端口 | 80 | 443 |
| 连接开销 | TCP 三次握手即可进入 HTTP 传输 | TCP 三次握手外，还要 SSL/TLS 握手 |
| 资源消耗 | 相对低 | 相对更耗服务器资源 |

## P1 作者强调的速度差异

视频中说 HTTP 页面响应速度通常比 HTTPS 快：HTTP 主要是 TCP 三次握手交换 3 个包；HTTPS 除了 TCP 的 3 个包，还要加上 SSL 握手所需的包，视频画面写到总计约 12 个包。

## P1 安全判断

- 传账号、密码、支付信息等敏感数据时，HTTP 明文传输风险高。
- HTTPS 的核心价值是加密、认证和完整性保护。

## 易错点

- 不要只把 HTTPS 理解成“端口不同”；它还引入证书、加密和完整性校验。
- HTTPS 更安全，但不是“没有任何成本”；作者提到证书成本和服务器资源开销。

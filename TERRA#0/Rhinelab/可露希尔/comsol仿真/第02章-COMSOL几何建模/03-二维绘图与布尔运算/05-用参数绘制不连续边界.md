# 用参数绘制不连续边界

## 09:30-10:30 作者先在画图工具解释边界

作者先画一个矩形，再画一条粗糙、不规则的内部边界。

这说明本段不是普通矩形绘制，而是让 COMSOL 接受不规则边界。

## 11:00-13:30 回到 COMSOL 构造边界

画面中几何树出现曲线类对象，最后在矩形中形成不规则曲线边界。

作者重点：不规则曲线要进入几何构造，不能只是画在屏幕上的线。

## P0 核心概念

**不连续边界**：边界形状不是简单直线、圆弧或规则图元，需要用曲线数据或参数表达。

在 COMSOL 中，曲线必须参与几何构建，才可以影响域、边界选择、网格和物理条件。

## P1 注意事项

| 问题 | 说明 |
|---|---|
| 曲线只显示但不分割域 | 后续无法作为边界条件使用 |
| 曲线点太密 | 网格可能过细 |
| 曲线太粗糙 | 容易生成短边和小面 |
| 曲线不闭合 | 不能直接形成封闭区域 |

## P2 作者例子总结

作者用手画粗糙线示意不规则边界，再在 COMSOL 中用曲线对象实现。

这个例子对应实际问题中的粗糙表面、材料界面、裂纹边界或不规则分界线。

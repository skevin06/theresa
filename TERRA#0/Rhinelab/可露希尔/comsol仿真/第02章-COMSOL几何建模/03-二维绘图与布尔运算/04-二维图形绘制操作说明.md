作者先用一页总图说明 COMSOL 二维绘图。

重点是：二维几何靠基本对象、变形复制和布尔运算组合。

## 05:30-06:30 添加二维对象

画面中作者在 COMSOL 几何菜单中添加二维对象，并生成圆形区域。

操作意图：先掌握最简单图元，再用属性面板控制坐标和尺寸。

## 07:00-08:30 复制/阵列圆孔

作者从一个圆点开始，逐步复制出一排圆点，再形成孔阵列。

这里对应 `复制`、`阵列`、`移动` 等操作，不是手工逐个画圆。

## 08:30-09:00 矩形减去圆阵列

画面出现矩形主体和大量圆孔。

操作逻辑：矩形为主体，圆阵列为扣除对象，使用差集得到多孔结构。

## P1 实际操作步骤：二维孔阵列

1. 新建 2D 几何。
2. 添加 Circle，设置半径和位置。
3. 用 Copy 或 Array 复制多个圆。
4. 添加 Rectangle 作为主体区域。
5. 使用 Difference。
6. 主体选 Rectangle，扣除对象选所有圆。
7. Build All，检查圆孔是否从矩形中扣除。

## P1 检查点

| 检查 | 目的 |
|---|---|
| 圆是否全在矩形内 | 避免差集失败或边界异常 |
| 圆阵列是否等距 | 后续参数化更稳定 |
| 差集后圆是否变成孔 | 确认可作为真实边界 |
| 孔边界是否可选 | 后续可施加条件或网格加密 |

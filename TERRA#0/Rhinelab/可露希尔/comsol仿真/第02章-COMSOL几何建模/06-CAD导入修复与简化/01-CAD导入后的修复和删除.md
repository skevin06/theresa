## P1 操作路径

```text
导入 CAD
├─ 检查单位和尺度
├─ 找短边 / 小面 / 狭长面 / 尖端
├─ 删除或修复不必要特征
├─ 必要时创建端盖面
├─ 缝合成实体
└─ 再进入网格控制
```

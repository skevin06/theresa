## P0 作者重点重排

```text
二维绘图
├─ 基本对象
├─ 阵列 / 移动 / 拷贝
├─ 布尔运算
└─ 参数或曲线构造不连续边界

三维绘图
├─ 由二维构建三维
├─ 三维基本对象
├─ 不同三维对象拼接
└─ 基本对象定义层

边界和求解相关几何
├─ PML 外层
├─ 装配体 / 联合体
├─ CAD 修复删除
└─ 网格控制特征
```

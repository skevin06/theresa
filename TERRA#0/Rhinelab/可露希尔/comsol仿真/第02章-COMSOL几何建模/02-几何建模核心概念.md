# 几何建模核心概念

## 04:30 几何建模方式选择

作者不是先讲抽象定义，而是先比较几何来源。

这决定后续能不能修改、能不能参数化、是否需要修复。

| 方式 | 视频时间 | 作者给出的重点 | 使用判断 |
|---|---:|---|---|
| 在 COMSOL 中绘制 | 04:30 | 完全在 COMSOL 中绘制，不需要其他软件 | 教学模型、参数几何 |
| LiveLink 模块 | 04:30 | 直接与现有 CAD 软件一起工作 | 已有 CAD 工作流 |
| 导入 CAD 数据 | 04:30 | CAD 经常需要修复和删除 | 工程复杂几何 |
| 导入 Mesh 数据 | 04:30 | 不可能进行修改 | 只有网格数据时 |

## P0 关键判断

**几何来源决定操作余地**。

COMSOL 内绘制便于参数化；CAD 导入更接近真实结构，但更可能需要清理。

## P1 视频中的例子对应

| 来源         | 作者例子                   |
| ---------- | ---------------------- |
| COMSOL 中绘制 | 圆、矩形、孔阵列、不连续边界         |
| 二维到三维      | 拉伸、旋转、扫掠               |
| 三维基本对象     | 立方体、圆锥体、圆柱、球、螺旋、金字塔、环圈 |
| CAD 导入     | 地形表面、轮轴、法兰、扳手          |
| Mesh/网格控制  | 为边界条件和材料属性简化几何         |

## P1 操作原则

```text
需要参数扫描 -> 优先 COMSOL 内绘制
已有复杂模型 -> 导入 CAD 后修复
只需求解不改几何 -> 可导入 Mesh
几何含小边小面 -> 先清理再网格
```

# 什么时候必须或不能使用装配体

## 27:00 形成装配体反例

作者先展示“形成装配体”的错误示意，画面标注 WRONG。

两个对象重叠时，如果本意是一个连续对象，却使用装配体，会得到错误物理结构。

## 28:30 形成联合体

作者展示形成联合体后：一个对象可以包含多个求解域。

联合体适合连续几何和连续物理场。

## 28:00-29:30 什么时候必须使用装配体

作者标题：**“什么时候必须使用装配体？”**

| 时间轴 | 作者列举 | 说明 |
|---|---|---|
| 28:00 | 两个对象形成接触对 | 在形成装配体步骤产生接触对 |
| 28:00 | 结构力学接触 | MEMS 和结构力学模块 |
| 28:00 | 求解域绕其他域旋转 | 旋转电磁场、流体混合 |
| 29:30 | 接触对/一致对上的连续性物理场 | 例如结构接触使接触体之间传热 |

## 30:00 什么时候可能用到装配体

作者讲不同对象不需要连续网格时，可考虑装配体。

画面比较：联合体、带配对装配体、不带配对装配体。

## 30:30-31:30 什么时候不能使用装配体

作者标题：**“什么时候不能使用装配体？”**

| 时间轴 | 作者列举 | 原因 |
|---|---|---|
| 30:30 | Maxwell 方程类 | 求解带旋度-旋度方程 |
| 30:30 | 三维电磁波 | RF 和波动光学模块 |
| 30:30 | 三维磁矢量方程 | AC/DC 模块 |

## P1 判断树

```text
两个对象接触或相邻
├─ 要形成连续实体 -> 形成联合体
├─ 要处理接触、旋转、混合 -> 装配体
└─ 求解三维电磁波或三维磁矢量方程 -> 不用装配体
```

## P2 作者例子

结构接触导致两个接触体之间传热，是作者在“必须使用装配体”里给出的连续性例子。

三维电磁波和所有三维磁矢量方程，是作者在“不能使用装配体”里强调的例子。

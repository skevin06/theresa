# 层的处理

## 18:00 基本对象可以定义层

作者展示：立方体、圆台、圆柱、球体等基本对象可以定义层。

画面中的对象都带有外层或壳层结构。

## P0 核心概念

层是附加在基本几何对象外侧或内侧的区域。

它不是后处理颜色，而是真正参与几何、材料、物理场或 PML 设置的区域。

## P1 操作思路

1. 先创建基本三维对象。
2. 在对象设置中启用层相关选项。
3. 设置层厚度和方向。
4. Build 后检查是否生成独立域或边界。
5. 给层分配材料、物理属性或 PML。

## P1 作者强调的用途

| 时间轴 | 用途 |
|---|---|
| 18:00 | 基本对象直接定义层 |
| 21:30 | 外圆外侧再加一层 |
| 22:00 | 外层作为 PML |
| 22:30-23:00 | COMSOL 中设置块体外层 |

## P2 例子

作者手画圆形区域时，先有内部真实区域，再在外面画一圈层。

这层随后被标成 PML，说明层可以作为波动问题的吸收区域。

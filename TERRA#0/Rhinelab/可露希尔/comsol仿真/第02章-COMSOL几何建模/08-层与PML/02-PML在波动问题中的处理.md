# PML 在波动问题中的处理

## 18:30-22:00 作者画图说明 PML

作者画了一个内部源、波传播方向、外部圆形边界。

随后在真实区域外面加一圈层，并标注 PML。

## P0 PML 是什么

PML 是波动问题中的外层吸收区域。

它用于模拟开放边界，减少波到达截断边界后的反射。

## P1 视频中的构造顺序

| 时间轴 | 画面 | 操作含义 |
|---|---|---|
| 18:30 | 内部源 | 建立波源位置 |
| 19:00 | 波向外传播 | 需要开放边界 |
| 19:30 | 外部圆形区域 | 真实计算区域 |
| 21:30 | 外面再加一圈 | 创建吸收层 |
| 22:00 | 标注 PML | 把外层设为 PML |

## P1 COMSOL 操作路径

1. 建立真实求解域。
2. 在真实域外侧创建一层包围区域。
3. 将外层单独保留为可选域。
4. 在对应波动物理场中把该域指定为 PML。
5. 检查 PML 不要覆盖真实物理区域。

## P1 使用判断

| 问题 | 是否考虑 PML |
|---|---|
| 声波向无限空间传播 | 是 |
| 电磁波向开放空间传播 | 是 |
| 机械波出射边界 | 可考虑 |
| 封闭腔体内部问题 | 通常不作为开放边界处理 |

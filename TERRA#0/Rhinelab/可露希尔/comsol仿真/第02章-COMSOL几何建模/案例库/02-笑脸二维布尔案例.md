# 笑脸二维布尔案例

## 14:00-14:30 作者给出的步骤

作者展示“其中一种解决方案”。

这个案例严格使用视频中的椭圆、矩形、交集、镜像、大圆和差集。

## P0 视频步骤表

| 时间轴 | 作者步骤 | COMSOL 意义 |
|---|---|---|
| 14:00 | 画两个椭圆，做差集 | 得到嘴部弧形基础 |
| 14:00 | 画一个矩形 | 用矩形裁剪椭圆差集结果 |
| 14:00 | 取交集 | 保留嘴部需要的部分 |
| 14:00 | 再画两个椭圆 | 构造嘴角或附加圆弧 |
| 14:00 | 做镜像 | 保证左右对称 |
| 14:00 | 做一个大圆，然后做个差集 | 大圆脸减去眼睛和嘴 |

## P1 操作逻辑

```text
脸 = 大圆 - 眼睛 - 嘴部形状
嘴部形状 = 椭圆差集 -> 矩形交集 -> 镜像补全
```

## P1 为什么这个例子重要

作者用它说明：复杂二维图形不是靠手画，而是靠对象组合。

每一步都要能在几何树中复现，否则后续参数化和修改会困难。

## P2 可迁移到 COMSOL 仿真

电阻梁打孔和笑脸挖眼睛是同一类操作。

主体域减去孔对象，结果得到新的边界和新的求解区域。

# 电阻梁几何优化案例

## 00:30 演示：微型电阻梁

作者用微型电阻梁作为 2P 的开场例子。

它包含热、电、结构三个物理场，不是单纯的几何图形。

## 01:00 耦合三个物理场

画面中出现热传导、电流守恒、结构力学相关方程。

几何会同时影响电流路径、温度分布和结构响应。

## 01:30 结果：微阻梁

作者展示计算得到电势、温度和位移。

后续还可扩展到优化、App 制作、三维非线性微结构模型。

## 02:00 优化目标

作者画面写：借助于优化设计一个 $0.4\Omega$ 的电阻。

目标函数显示为：

$$
\mathrm{abs}(1/\mathrm{comp1.ec.G11})-0.4
$$

## 02:00 设计变量

画面写：

$$
0 < \text{孔半径} < \text{宽度}
$$

## P0 几何意义

孔半径和宽度不是几何装饰。

它们直接改变导电通道，从而改变等效电阻。

## P1 COMSOL 操作映射

| 几何对象 | 操作 |
|---|---|
| 电阻梁主体 | 绘制或导入三维几何 |
| 孔 | 用圆柱或二维圆拉伸后差集 |
| 孔半径 | 设为参数 |
| 梁宽 | 设为参数 |
| 优化目标 | 通过求解结果构造目标函数 |

## P2 作者例子重点

第二章所有几何操作最终都能回到这个例子：

用参数几何构造可优化模型，而不是只画一个固定图形。

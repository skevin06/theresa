# 层与 PML 操作案例

## 18:30-22:00 视频例子

作者手画一个内部源，波向外传播。

随后在外部画一圈包围层，并在外层标注 PML。

## P0 案例结构

```text
内部源
└─ 波向外传播
   └─ 真实计算区域
      └─ 外层 PML
```

## P1 时间轴记录

| 时间轴 | 画面 | 操作含义 |
|---|---|---|
| 18:30 | 内部有源 | 波动问题的激励位置 |
| 19:00 | 波向右传播 | 出射波需要处理开放边界 |
| 19:30 | 外部圆形区域 | 建真实求解域 |
| 21:30 | 外侧加一层圆环 | 创建外层域 |
| 22:00 | 外层写 PML | 外层指定为吸收层 |

## P1 操作原则

PML 必须是能单独选择的外层域。

它包围真实求解区域，但不代表真实材料结构。

## P2 作者提示

作者手写“电、声、机”，表示电磁波、声波、机械波类问题都可能用到这类外层处理。

这个案例只记录视频里的圆形外层示意，不额外扩展成其他几何。

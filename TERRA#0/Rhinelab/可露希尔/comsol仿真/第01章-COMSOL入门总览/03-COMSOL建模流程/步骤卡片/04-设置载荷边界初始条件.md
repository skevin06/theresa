# 设置载荷、边界条件和初始条件

## P0 核心定义

边界条件描述模型如何与外部世界连接。

载荷和初始条件决定问题是否可求、是否符合现实。

## P1 技术要点

| 类型 | 作用 |
|---|---|
| 载荷 | 外部力、热源、电流、压力 |
| 边界条件 | 固定、绝缘、接地、温度、通量 |
| 初始条件 | 瞬态计算的起点 |

## P2 例子

电场问题常设电势端和接地端；结构问题常设固定端和力载荷。

电磁学例子中，一端设置 $V=V_0$，另一端设置 Ground。

侧壁通常设为 Electric Insulation，即 $\mathbf{n}\cdot\mathbf{J}=0$。

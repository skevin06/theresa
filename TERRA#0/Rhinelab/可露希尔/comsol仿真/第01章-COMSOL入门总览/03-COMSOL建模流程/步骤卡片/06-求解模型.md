# 求解模型

## P0 核心定义

求解是把模型交给数值算法计算。

求解类型决定计算的是稳态、瞬态、频域还是参数变化。

## P1 技术要点

| 求解类型 | 用途 |
|---|---|
| 稳态 | 求平衡状态 |
| 瞬态 | 求时间演化 |
| 频域 | 求周期激励响应 |
| 参数扫描 | 看参数变化趋势 |

## P2 例子

电阻梁可先做稳态电流求解，再扫描孔半径观察电阻变化。

稳态电磁例子求解的是 $\nabla\cdot(-\sigma\nabla V)=0$。

求解得到 $V$ 后，COMSOL 自动派生 $\mathbf{E}$ 和 $\mathbf{J}$。

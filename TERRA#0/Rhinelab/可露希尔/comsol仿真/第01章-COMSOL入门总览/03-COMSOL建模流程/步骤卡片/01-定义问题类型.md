# 定义问题类型

## P0 核心定义

确定模型要解决什么物理问题，先于任何软件操作。

问题类型决定物理接口、变量、方程和研究类型。

## P1 技术要点

| 判断项 | 关键词 |
|---|---|
| 求什么 | 温度、位移、电势、速度、浓度 |
| 已知什么 | 尺寸、材料、载荷、边界 |
| 时间类型 | 稳态、瞬态、频域 |
| 耦合类型 | 单物理场、弱耦合、强耦合 |

## P2 例子

电阻梁：目标是求电阻或电流分布，主物理场是稳恒电流。

详细推导：[[../../案例库/01-电磁学例子-电势电场与稳恒电流仿真]]

建模时先把未知量选为电势 $V$，而不是直接求电阻。

电阻由端电压 $U$ 和积分电流 $I$ 后处理得到：$R=U/I$。

# COMSOL 建模流程总览

## P0 核心定义

COMSOL 建模流程是把真实问题逐层翻译成可求解数值模型的过程。

每一步都服务于同一个目标：让物理问题被正确离散、求解和解释。

## P0 流程树

```text
问题类型
├─ 几何
│  └─ 计算区域
├─ 材料
│  └─ 物性参数
├─ 条件
│  ├─ 载荷
│  ├─ 边界条件
│  └─ 初始条件
├─ 网格
│  └─ 离散化
├─ 求解
│  └─ 数值计算
├─ 后处理
│  └─ 结果解释
└─ 修改优化
   └─ 迭代改进
```

## P1 八步速览

| 顺序 | 步骤 | 核心产物 |
|---|---|---|
| 1 | 定义要求解的问题类型 | 物理模型 |
| 2 | 绘制或导入 CAD 几何 | 计算区域 |
| 3 | 定义材料属性 | 物性参数 |
| 4 | 设置载荷、边界条件和初始条件 | 外部作用 |
| 5 | 网格划分 | 离散模型 |
| 6 | 求解模型 | 数值解 |
| 7 | 后处理和报告结果 | 可解释结论 |
| 8 | 修改和优化 | 设计改进 |

## P2 例子

电阻梁问题可映射为：定义电流问题 -> 建几何 -> 设材料电导率 -> 加电势边界 -> 划网格 -> 求电阻 -> 看电流密度 -> 优化尺寸。

电磁学详细案例：[[../案例库/01-电磁学例子-电势电场与稳恒电流仿真]]

```text
电压差 U
└─ 电势 V
   └─ 电场 E = -grad(V)
      └─ 电流密度 J = sigma E
         └─ 端子积分得到 I
            └─ 等效电阻 R = U / I
```

# 后处理和报告结果

## P0 核心定义

后处理是把数值解转化为可判断、可复现、可汇报的信息。

报告不是截图堆砌，而是“模型假设 + 参数 + 结果 + 结论”。

## P1 技术要点

| 后处理对象 | 作用 |
|---|---|
| 云图 | 看空间分布 |
| 等值线 | 看梯度和区域边界 |
| 切片 | 看内部场变量 |
| 路径图 | 看沿线变化 |
| 积分 | 求总流量、总热量、总力 |
| 最大/最小值 | 找危险点或热点 |

## P1 结果表达

$$
\text{可信结论}=\text{正确变量}+\text{正确单位}+\text{合理范围}+\text{可复现设置}
$$

## P2 例子

**电流密度云图**：可识别孔边和尖角附近的电流集中。

**温度云图**：可定位热点；但热点要结合网格检查，避免数值奇异。

### 电磁学例子后处理

| 结果 | 看什么 | 判断 |
|---|---|---|
| $V$ 云图 | 电势从高到低是否平滑下降 | 验证边界方向 |
| $\mathbf{E}$ 箭头 | 电场方向和强弱 | 验证 $-\nabla V$ |
| $\mathbf{J}$ 云图 | 电流集中区域 | 找热点风险 |
| 端子电流 $I$ | 总电流 | 计算等效电阻 |
| $R=U/I$ | 设计目标 | 用于优化 |

报告中要同时给出边界设置和材料电导率，否则电阻结果不可复现。

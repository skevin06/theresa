# 设置载荷、边界条件和初始条件

## P0 核心定义

边界条件是模型与外界交换物理量的接口。

缺少正确边界，模型就无法代表真实实验或工况。

## P1 技术要点

| 条件 | 作用 | 典型项 |
|---|---|---|
| 载荷 | 主动施加外部作用 | 力、压力、热源、电流 |
| 边界条件 | 约束边界行为 | 固定、接地、绝缘、温度 |
| 初始条件 | 指定时间起点 | 初温、初速、初浓度 |

## P1 判断路径

```text
外界给定值 -> Dirichlet 条件
外界给定通量 -> Neumann 条件
外界有换热/接触 -> 混合或耦合边界
瞬态问题 -> 必须检查初始条件
```

## P2 例子

**电场例子**：一端设电势，另一端接地，侧面可设绝缘。

**结构例子**：一端固定，另一端施加力或位移，用来模拟夹持和加载。

### 电磁学例子边界

| 边界 | 设置 | 方程含义 |
|---|---|---|
| 输入端 | $V=V_0$ | 给定高电势 |
| 输出端 | $V=0$ | 设定参考电势 |
| 侧壁 | $\mathbf{n}\cdot\mathbf{J}=0$ | 绝缘，无电流穿出 |
| 端子 | Terminal | 提取总电流 |

没有 Ground 时，电势零点不确定，线性系统可能奇异。

# 求解模型

## P0 核心定义

求解模型就是运行数值算法，得到物理变量的近似解。

求解成功不等于结果正确，必须检查物理合理性。

## P1 技术要点

| 求解设置 | 作用 |
|---|---|
| 稳态研究 | 求最终平衡 |
| 瞬态研究 | 求时间过程 |
| 频域研究 | 求周期响应 |
| 参数扫描 | 比较不同参数 |
| 分步求解 | 降低强耦合难度 |

## P1 收敛排查

```text
不收敛
├─ 边界条件错误
├─ 材料参数量级错误
├─ 网格质量差
├─ 初值太差
└─ 耦合太强，需要分步加载
```

## P2 例子

**电阻梁**：先固定几何做稳态电流求解，再扫描孔半径。

若参数扫描每一步都失败，应先回到单个参数点检查边界和网格。

### 电磁学例子求解

稳恒电流求解的核心方程：

$$
\nabla \cdot (-\sigma \nabla V)=0
$$

求解变量是 $V$，$\mathbf{E}$ 与 $\mathbf{J}$ 是后续派生量。

如果模型出现奇异矩阵，优先检查是否缺少 Ground 或参考电势。

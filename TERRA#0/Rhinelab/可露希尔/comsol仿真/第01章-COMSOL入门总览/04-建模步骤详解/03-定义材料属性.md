# 定义材料属性

## P0 核心定义

材料属性是方程系数。

它决定模型变量如何响应载荷和边界条件。

## P1 技术要点

| 物理场 | 核心参数 | 常见错误 |
|---|---|---|
| 传热 | k, Cp, rho | 漏填热容或密度 |
| 结构 | E, nu, rho | MPa 和 Pa 混用 |
| 电流 | sigma, epsilon | 电导率单位错 |
| 流体 | mu, rho | 动力黏度和运动黏度混用 |

## P1 单位意识

$$
\text{数值可靠性} \approx \text{参数来源可靠} \times \text{单位一致}
$$

## P2 例子

**电阻梁**：材料电导率决定电流分布和等效电阻。

**传热问题**：导热系数决定温度梯度，热容决定瞬态升温速度。

### 电磁学例子

材料中最关键的参数是电导率 $\sigma$。

在均匀导体中，$\sigma$ 可设为常数；在温度耦合问题中，$\sigma$ 可设为 $\sigma(T)$。

| 材料情况  | 建模方式                 | 影响       |
| ----- | -------------------- | -------- |
| 均匀导体  | 常数 $\sigma$          | 电势近似线性变化 |
| 非均匀材料 | 空间函数 $\sigma(x,y,z)$ | 电流绕开低导电区 |
| 温度相关  | 函数 $\sigma(T)$       | 电-热耦合反馈  |

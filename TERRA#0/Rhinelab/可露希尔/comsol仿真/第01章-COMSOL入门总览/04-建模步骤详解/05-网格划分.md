# 网格划分

## P0 核心定义

网格是连续问题到离散问题的桥。

网格质量决定计算精度、稳定性和速度。

## P1 技术要点

| 网格策略 | 作用 |
|---|---|
| 粗网格 | 快速检查模型是否能跑 |
| 细网格 | 提高关键区域精度 |
| 局部加密 | 节约计算量并捕捉梯度 |
| 边界层网格 | 处理流体近壁或薄层效应 |
| 网格无关性 | 验证结果不随网格改变 |

## P1 网格风险

```text
小孔 / 尖角 / 薄层 / 接触边
└─ 局部梯度高
   └─ 需要加密
      └─ 计算量增加
```

## P2 例子

**电阻梁孔边缘**：电流密度容易集中，孔边网格应比远离孔的区域更细。

**薄壁结构**：厚度方向至少要有足够单元，否则弯曲或热梯度不可信。

### 电磁学例子网格

电流密度 $\mathbf{J}$ 在尖角、孔边、窄缝处变化更快。

这些区域对应 $\nabla V$ 的局部强梯度，网格需要局部加密。

| 区域 | 风险 | 处理 |
|---|---|---|
| 孔边 | 电流绕流集中 | 局部加密 |
| 尖角 | 场强奇异或近似奇异 | 倒圆角或加密 |
| 细长通道 | 电流路径受限 | 厚度方向保证单元数 |
| 端子边界 | 积分电流敏感 | 边界附近检查网格 |

# 定义要求解的问题类型

## P0 核心定义

问题类型是 COMSOL 模型的入口。

它回答：这个模型要解哪个物理过程、哪个变量、哪个状态。

## P0 决策公式

$$
\text{模型目标}=\text{求解变量}+\text{物理机制}+\text{空间范围}+\text{时间类型}
$$

## P1 技术要点

| 决策项 | 高密度提示 |
|---|---|
| 求解变量 | 温度 T、位移 u、电势 V、速度 v、浓度 c |
| 物理机制 | 热传导、弹性变形、电流传导、流动、扩散 |
| 时间类型 | 稳态看最终平衡，瞬态看过程变化 |
| 维度选择 | 2D 简化、2D 轴对称、3D 完整模型 |
| 耦合判断 | 先确认单物理场，再增加耦合项 |

## P1 关系树

```text
问题定义
├─ 主变量
├─ 控制方程
├─ 几何维度
├─ 材料参数
├─ 边界条件
└─ 研究类型
```

## P2 例子

**电阻梁优化**：目标是让电阻接近 0.4Ω，设计变量可以是孔半径和梁宽。

该问题主变量是电势 V，结果量可由电流和电压换算得到。

完整案例：[[../案例库/01-电磁学例子-电势电场与稳恒电流仿真]]

### 电磁学建模思路

先不要把“求电阻”当成直接未知量。

应先求电势 $V$，由电势推导电场和电流，再后处理得到电阻。

```text
未知量 V
└─ E = -grad(V)
   └─ J = sigma E
      └─ I = ∫ J·n dS
         └─ R = U / I
```

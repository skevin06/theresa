# 绘制或导入 CAD 几何

## P0 核心定义

几何是物理方程的求解域。

仿真几何追求物理有效，不追求制造细节完整。

## P1 技术要点

| 技术点 | 说明 |
|---|---|
| 参数化尺寸 | 用变量控制长度、半径、厚度 |
| 布尔运算 | 并集、差集、交集、分割 |
| 工作平面 | 在 3D 中绘制 2D 截面 |
| 拉伸/旋转 | 从二维截面生成三维体 |
| CAD 修复 | 删除碎面、小边、短线、无关倒角 |

## P1 几何选择

```text
简单规则形状 -> COMSOL 内建
复杂工程外形 -> CAD 导入
强参数优化 -> 优先参数化几何
网格困难 -> 先做几何简化
```

## P2 例子

**笑脸几何**：用圆、椭圆、矩形和差集组合，说明复杂二维形状来自基础图元。

**电阻梁**：孔、梁宽、端部结构是关键几何；无关小倒角可先忽略。

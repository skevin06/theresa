# 多物理场解决方案

## P0 

==所谓物理场就是底层数理方程的不一样==

**多物理场**：多个物理过程在同一模型中同时存在，并且变量之间互相影响。

COMSOL 的核心价值不是“画图求解”，而是把不同物理场放到同一个数学模型中耦合。

## P0 核心关系

| 关系   | 含义              | 判断关键词          |     |
| ---- | --------------- | -------------- | --- |
| 单物理场 | 只有一种主导机制        | 只求温度、只求位移、只求电势 |     |
| 弱耦合  | 一个场影响另一个场，但反馈较弱 | 先电后热、先流后热      |     |
| 强耦合  | 多个场互相反馈         | 热变形影响电阻，流动影响传热 |     |
| 多尺度  | 尺寸或时间尺度差异明显     | 微结构、薄层、瞬态冲击    |     |

## P0 物理场类型

```text
多物理场
├─ 电磁场
├─ 结构力学
├─ 传热
├─ 流体力学
├─ 化学反应
├─ 声学
└─ 用户自定义 PDE
```

## P1 技术要点

**先拆后合**：复杂耦合模型不要一开始全开，先确认每个单物理场能独立跑通。

**先物理后软件**：先写清变量、方程、边界，再决定选哪个 COMSOL 接口。

## P1 建模判断表

| 现象       | 可能物理场 | 可能耦合  |
| -------- | ----- | ----- |
| 通电后升温    | 电流、传热 | 焦耳热   |
| 升温后变形    | 传热、结构 | 热膨胀   |
| 流体带走热量   | 流体、传热 | 共轭传热  |
| 电磁波加热材料  | 电磁、传热 | 微波加热  |
| 浓度影响反应速率 | 传质、化学 | 反应-扩散 |

## P1 数学视角

多物理场可以理解为多个方程组共享变量：

$$
\mathcal{F}_1(u,T,\phi)=0,\quad
\mathcal{F}_2(u,T,\phi)=0,\quad
\mathcal{F}_3(u,T,\phi)=0
$$

变量互相进入对方方程时，就形成耦合。

## P2 例子

**电磁加热**：电磁场产生损耗，损耗变成热源，温度再改变材料参数。

**热-结构耦合**：温度升高导致热膨胀，结构变形又可能改变接触或边界状态。

**流固耦合**：流体压力作用在结构上，结构形变又改变流体通道。

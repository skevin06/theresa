# COMSOL 能做什么

## P0 核心定义

**COMSOL Multiphysics** 是多物理场有限元仿真平台。

它把几何、材料、方程、边界、网格、求解和后处理放在同一个建模环境里。

## P0 能力边界

| 能力     | 说明              | 关键词          |
| ------ | --------------- | ------------ |
| 多物理场耦合 | 把不同物理过程放在同一模型中  | 电-热、热-结构、流-热 |
| 自定义方程  | 可输入 PDE、ODE、弱形式 | 自定义物理接口      |
| 参数化建模  | 尺寸、材料、载荷可设为参数   | 参数扫描、优化      |
| 几何建模   | 可绘制或导入 CAD      | 布尔运算、拉伸、旋转   |
| 网格控制   | 全局或局部控制网格精度     | 边界层、局部加密     |
| 后处理    | 输出云图、曲线、积分、表格   | 结果解释、报告      |

## P0 软件定位

COMSOL 不是单纯 CAD 软件，也不是只会出图的工具。

它更像是“物理方程 + 数值求解 + 工程建模”的集成平台。

## P1 技术要点

**可定制**：内置接口不够时，可以用 PDE、弱形式、变量和函数补充。

**可扩展**：不同模块扩展不同物理领域，但模块通常需要对应许可证。

## P1 模块关系

```text
COMSOL Multiphysics 基础平台
├─ 结构力学模块
├─ 传热模块
├─ AC/DC 模块
├─ CFD 模块
├─ 化学反应工程模块
├─ RF / 波动光学模块
└─ Optimization / CAD Import 等辅助模块
```

## P1 使用判断

| 问题类型 | COMSOL 是否适合 | 注意点 |
|---|---|---|
| 复杂耦合物理 | 很适合 | 需要先理解物理关系 |
| 标准结构静力学 | 适合 | 结构模块许可可能需要 |
| 纯 CAD 绘图 | 不优先 | 专业 CAD 更高效 |
| 大规模工业 CFD | 视情况 | 计算资源和湍流模型很关键 |
| 自定义 PDE | 很适合 | 方程、边界、单位要明确 |

## P2 例子

**优化电阻梁**：几何尺寸影响电阻，电阻目标可以作为优化约束或目标函数。

**微波加热**：电磁波在材料中损耗，损耗转化为热源，属于电磁-传热耦合。

**低频电磁场**：电势、电流密度、材料电导率共同决定电场分布。

详见：[[../案例库/01-电磁学例子-电势电场与稳恒电流仿真]]

### 电磁学例子思路

先把未知量定为电势 $V$，再用 $\mathbf{E}=-\nabla V$ 得到电场。

再用 $\mathbf{J}=\sigma\mathbf{E}$ 和 $\nabla\cdot\mathbf{J}=0$ 形成稳恒电流方程。

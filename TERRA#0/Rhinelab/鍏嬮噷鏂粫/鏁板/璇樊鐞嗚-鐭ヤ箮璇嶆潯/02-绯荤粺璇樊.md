# 系统误差

| 来源轴 | 来源位置 | 内容 |

## P0 核心定义

系统误差是有规律的偏差：在相同条件下重复测量同一对象，测量结果总朝某一方向偏离，或按可预知方式变化。

| 类型 | 判断方式 | 处理重点 |
|---|---|---|
| 定值系统误差 | 误差大小和符号基本不变 | 找偏倚来源，校准或修正 |
| 变值系统误差 | 随条件变化而按规律变化 | 找变化条件，建立修正关系 |

## P0 与随机误差的区别

| 比较项 | 系统误差 | 随机误差 |
|---|---|---|
| 方向 | 常偏向同一侧 | 方向不可预知 |
| 规律 | 有规律或可预知 | 只有统计规律 |
| 平均能否消除 | 多次平均不能直接消除 | 多次测量可减弱影响 |
| 常见处理 | 校准、修正、改进方法 | 重复测量、统计分析 |

## P1 判断步骤

1. 固定测量对象、方法、仪器、环境和人员。
2. 多次重复测量。
3. 看偏差是否总偏大或总偏小。
4. 如果偏差随温度、时间、仪器漂移等条件变化，记录变化条件。
5. 用校准或修正量处理，而不是只求平均值。

# 测量误差模型

## P0 来源轴

| 来源轴 | 来源位置 | 内容 |
|---|---|---|
| ZH-02 | 知乎盐选“1.3 测量量表和问卷设计” | 测量值不是特征真实值，而是一次观察 |
| ZH-02 | 同一章节公式段 | 观察值可分解为真实值、系统误差和随机误差 |

## P0 公式

知乎盐选中给出的测量表达可以整理为：

$$
X_O = X_T + X_S + X_R
$$

| 符号 | 含义 |
|---|---|
| $X_O$ | 观察值 |
| $X_T$ | 真实值 |
| $X_S$ | 系统误差 |
| $X_R$ | 随机误差 |

## P0 解释

测量值不是“对象本身”，而是测量过程得到的观察结果。误差理论要做的事，是把观察值里哪些部分来自真实特征、哪些来自稳定偏差、哪些来自临时波动分清。

## P1 使用步骤

1. 先明确被测特性。
2. 把测得数值作为观察值 $X_O$。
3. 检查是否存在稳定方向的偏差，记为 $X_S$。
4. 检查重复测量中的临时波动，记为 $X_R$。
5. 用信度、效度或工程测量指标判断该测量是否可用。
